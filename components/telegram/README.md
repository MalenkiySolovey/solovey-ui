# Telegram product adapters

The administrative Telegram feature and UI source live in [solovey-component-telegram](https://github.com/MalenkiySolovey/solovey-component-telegram). components/sources.lock.json binds the accepted module, source and frontend input identities. component.json here is a generated, read-only compatibility input; preparation rejects drift against the accepted source.

This directory retains only product registration and existing Panel HTTP authorization, settings/SecretRef persistence, proxy policy, audit, Backup encryption/restore and CLI adapters. Delivery, queue/retry, discovery, settings definitions, jobs and the Vue contribution compile from the external module. Edit their canonical source repository.
