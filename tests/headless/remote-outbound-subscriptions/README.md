# Headless remote subscription source consumer

This independent test module consumes the exact immutable feature and Host versions selected by the Product source lock. It exercises accepted snapshot normalization, endpoint identity and resource relationships without importing Product or copying its algorithms. Missing Backend transport and parser authority fail closed; construction starts no scheduler.

The Node checkout and production Node authority remain unchanged. This bounded harness does not implement a Node Agent, enrollment, source database, controller transport, publication or autonomous source refresh. Those capabilities require a separately accepted embedding and authorization model.

The Product script verifies version, checksum, source identity and dependency closure before Linux and Windows race tests.
